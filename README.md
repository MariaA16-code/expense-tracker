## Expense Analytics Dashboard

A simple web-based expense tracker with basic analytics and visualizations.

## Features

Add and delete expenses

Track spending by category

Monthly spending analysis

Interactive charts and KPIs

Date and category filters

CSV export

## Tech Stack

Python • Flask • MySQL • HTML • CSS • JavaScript • Chart.js

Run Locally

pip install -r requirements.txt
python app.py

Configure your MySQL connection in a local .env file before running.

## Purpose

A practical portfolio project demonstrating data handling, basic analytics, and data visualization.
